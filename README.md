# lemontree-menu
เว็บเมนู Lemon Tree House — หน้าเดียว ดูในมือถือได้

## วิธีแก้เมนู
เปิด `index.html` แล้วแก้ข้อมูลใน `const MENU = [...]` (ชื่อ, คำอธิบาย, ราคา, รูป, ป้าย)

## รูป
วางไฟล์รูปใน `images/` ให้ชื่อตรงกับช่อง `img` — ถ้าไม่มีรูปจะแสดง emoji แทน

## เปิดดู
เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือเปิด GitHub Pages (Settings → Pages → branch main / root)
